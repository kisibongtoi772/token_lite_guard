How it works API keys saved here are stored in the local SQLite database (data/token_guard.db). The proxy reads them before checking your .env file, so you do not need to restart the server after saving. Local providers (Ollama, LM Studio) do not require an API key. To remove a key from the database and revert to the .env value, click the clear button.
